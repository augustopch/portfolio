Jarvis

Jarvis is a private, local-first assistant that I build and run for myself, on my own computer. It is not a public service, there is no sign-up, and nobody else uses it.

With my permission, it reads my own health and fitness data (activity, sleep, body measurements) from the Google Health API, read-only, so it can answer my questions about it.
