Privacy policy

Last updated 5 November 2026

Jarvis is a personal application. It is used by its developer only, Augusto Peña, and it reads only his own data.

What Jarvis accesses

When I grant permission through Google's consent screen, Jarvis reads my own data from the Google Health API, read-only. The data covers activity and fitness, health metrics and measurements, and sleep. Jarvis cannot write to or change this data.

How it is used

The data is used only to answer my own questions inside Jarvis and to show me summaries of my own health. It is not used for advertising, not sold, not used to build profiles of anyone else, and not used to train general-purpose AI models.

Where it is stored

The data and the access token are stored locally, on my own computer. They are not uploaded to a server run by anyone else. A question I ask may be processed by a language-model provider configured in Jarvis, and only under that provider's data-retention settings, which are set to deny data collection.

Sharing

Data is not shared with or transferred to any third party, except the model processing described above, which I control.

Limited Use

Jarvis's use and transfer of information received from Google APIs follows the Google API Services User Data Policy, including its Limited Use requirements.

Revoking access and deletion

Access can be revoked at any time at myaccount.google.com/permissions. When it is revoked, the token stops working, and the locally stored copy can be deleted from my computer.
